## Intro
* NestJS project code base
* Each feature is stored in a branch

## Init
* `npm i -g @nestjs/cli`
* `nest new project-name`
* `npm i class-validator class-transformer`

## Config
* `npm i @nestjs/config`

## Redis
* `npm i redis`

### Data types
* String
* Hash: Store a flat object
* List: Lists of strings, ordered by insertion order
* Set: Unordered collection of unique strings
* Sorted Set: Ordered collection of unique strings with score
