## Intro
* NestJS project code base
* Each feature is stored in a branch

## Init
* `npm i -g @nestjs/cli`
* `nest new project-name`
* `npm i class-validator class-transformer`

## Stream
* Using compress middleware will result in client receive everythin at once instead of chunks
* File type, file name can be either set with header or from `StreamableFile` stream options
