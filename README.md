## Intro
* NestJS project code base
* Each feature is stored in a branch

## Init
* `npm i -g @nestjs/cli`
* `nest new project-name`
* `npm i class-validator class-transformer`

## Ultimate Express
* `npm i ultimate-express`
* `ultimate-express` is the fastest http server with full Express compatibility, based on µWebSockets
* NOTE: the adapter is copied from Nestjs' express adapter
