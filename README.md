## Intro
* NestJS project code base
* Each feature is stored in a branch

## Init
* `npm i -g @nestjs/cli`
* `nest new project-name`
* `npm i class-validator class-transformer`

## Winston
* `npm i nest-winston winston winston-daily-rotate-file`
* This example replace nest logger with winston, more config can be found at [nest-winston](https://www.npmjs.com/package/nest-winston)
